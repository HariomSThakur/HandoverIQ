# Campus Makers Portal — Project Overview

This synthetic project is a small web portal for a university makers club. The portal lists workshops, accepts member registrations, and gives volunteer coordinators a simple attendance export. The incoming developer should first confirm which events are active and whether the export still matches the club's spreadsheet.

The current prototype uses Flask, SQLite, and server-rendered pages. The production deployment runs on a small club-managed virtual machine. No live credentials or personal member data are included in this demo.
